# Worldwide-National-Space-Agency-Status-2025-
A database of the status of national space agencies worldwide, including their current capabilities and the proposed national space agencies of the world.

The source is Wikipedia (useless to search further as this is official information).
The current statuses (capabilities), include:

  1) Human Spaceflight capability (Highest tier)
  2) Extraterrestrial Exploration Capability
  3) Launch Capability
  4) Has Space Agency (No launch capability)
  5) Proposed space agency (not in the dataset, included separately in a map)
     
The file is included in a CSV format, and map is included separately, further showing the proposed space agencies (that are in progress).
